# Agent notes

## Releases

Follow "Releasing" in `README.md`. Pick the version bump by the size of the change:

- **Patch** (`1.1.0` → `1.1.1`): the default for every release.
- **Minor** (`1.1.0` → `1.2.0`): only for a bigger than usual change, such as a new feature or a
  changed default.
- **Major** (`1.1.0` → `2.0.0`): only for a breaking change, such as removed entities, changed
  entity ids, or a config entry that needs migrating.
